# Dossier images

Placez ici vos photos et vidéos définitives (idéalement en `.webp` / `.avif`
pour les photos, `.mp4` pour les vidéos), puis remplacez les composants
`<PhotoPlaceholder label="..." />` correspondants par de vrais `next/image`
ou `<video>`. Voir la section "Assets à fournir" du README principal pour
la liste complète des médias attendus.
